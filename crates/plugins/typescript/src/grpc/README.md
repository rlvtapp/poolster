# TypeScript gRPC package

Poolster emits this Node.js 20+ ESM package directly. No protoc or third-party source generator is invoked. Install the pinned @bufbuild/protobuf 2.16.0 and @grpc/grpc-js 1.14.6 runtimes with `npm install`, then compile with `npm run build`. Each Protobuf file has its own `src/<path>.ts` module and corresponding JavaScript/declaration modules under `dist`. Import through a package subpath such as `your-package/service`.

Messages expose native Buf `Message` types and `<Message>Schema` descriptors. Use `create(Schema, values)`, `fromBinary` and `toBinary` from @bufbuild/protobuf. Service modules expose typed grpc-js clients, server interfaces and registration definitions. Implement `<Service>Server`, register it with `server.addService(<Service>Service, implementation)`, and construct `<Service>Client` with explicit target and credentials. Unary and all streaming directions use native grpc-js callback/stream APIs, including metadata, deadlines, cancellation, status errors and channel settings. The package root and service subpaths expose Node gRPC. Browser applications import the `/browser` entry or `.messages` and selected HTTP adapter subpaths; these do not load grpc-js. Binary gRPC-web supports unary/server streaming, and Twirp supports unary calls. Unsupported adapter streams fail before I/O.

Poolster-owned wire projections generate fields and references. Retained descriptors hydrate the runtime registry to preserve wire behavior, presence, maps, defaults and unknown fields. Use `isFieldSet(message, Schema.field.fieldName)` to inspect explicit presence: proto2 fields with declared defaults return their default even when unset. Wide integers use bigint. Oneofs use `{case, value}` discriminated unions. Proto2 groups and extensions retain native descriptor semantics; editions are rejected by the current parser. HTTP annotations do not create HTTP clients. Source files remain under `proto/`; all generated files use normal Poolster ownership/customization. Dependency installation is separate from generation and no tools are downloaded while generating.


Select raw/flat/idiomatic facades with clientStyle. Optional NiceGrpc/NestJS adapters use pinned runtime libraries. Immutable views return defensive snapshots; reactive streams preserve native call metadata/status/cancel. Alternate typed Value models retain native codecs and wire identities. Change optional fields and oneof tags normally; current values determine presence. Use ValueCodec.clone(value) to copy a value while retaining unknown wire fields. Object spreads, JSON copies and reconstruction do not retain the hidden wire-origin snapshot. Checked conversions reject integer/date/duration precision loss instead of rounding.
