# TypeScript gRPC package

Poolster emits this Node.js 20+ ESM package directly. No protoc or third-party source generator is invoked. Install the pinned @bufbuild/protobuf 2.16.0 and @grpc/grpc-js 1.14.6 runtimes with `npm install`, then compile with `npm run build`. Each Protobuf file has its own `src/<path>.ts` module and corresponding JavaScript/declaration modules under `dist`. Import through a package subpath such as `your-package/service`.

Messages expose native Buf `Message` types and `<Message>Schema` descriptors. Use `create(Schema, values)`, `fromBinary` and `toBinary` from @bufbuild/protobuf. Service modules expose typed grpc-js clients, server interfaces and registration definitions. Implement `<Service>Server`, register it with `server.addService(<Service>Service, implementation)`, and construct `<Service>Client` with explicit target and credentials. Unary and all streaming directions use native grpc-js callback/stream APIs, including metadata, deadlines, cancellation, status errors and channel settings. This output is for Node, not browser grpc-web.

Poolster-owned wire projections generate fields and references. Retained descriptors hydrate the runtime registry to preserve wire behavior, presence, maps, defaults and unknown fields. Use `isFieldSet(message, Schema.field.fieldName)` to inspect explicit presence: proto2 fields with declared defaults return their default even when unset. Wide integers use bigint. Oneofs use `{case, value}` discriminated unions. Protobuf groups and extensions fail explicitly; editions are rejected by the current parser. HTTP annotations do not create HTTP clients. Source files remain under `proto/`; all generated files use normal Poolster ownership/customization. Dependency installation is separate from generation and no tools are downloaded while generating.
