# Poolster 0.5.0

Poolster 0.5.0 promotes the alpha.4 generation pipelines and fixes to the stable
channel. The [support matrix](../plugin-support-matrix.md) documents supported
protocols, language outputs and their limits.

## Install

```sh
npm install -D @relevate/poolster@0.5.0 @relevate/poolster-plugin-typescript@0.5.0
npm install -D poolster@0.5.0
python -m pip install poolster==0.5.0
cargo install poolster-cli --version 0.5.0 --locked
```

The JavaScript SDK, CLI, plugins and Rust crates share version 0.5.0. Stable npm
publication uses the `latest` dist-tag; previous alpha releases remain available
by their exact versions.

## Changes

- GraphQL clients across ten SDK languages, AsyncAPI models and Kafka clients,
  native Protobuf/gRPC outputs, and TypeScript Arazzo workflows.
- Alpha.4 fixes for TypeScript names, query hooks, Faker schema annotations,
  MSW request origins, Go module paths and optional integration dependencies.
- Configured authors and licenses reach generated SDK package manifests.
- Generated C# NuGet packages include their README; Ruby gem metadata is checked
  during generation and CI packaging.
- SDK publishing waits for registry propagation after successful uploads while
  preserving strict artifact verification.

See the [changelog](../../CHANGELOG.md) and
[installation guides](../README.md). Publication runs the Rust, native SDK,
Kafka and launcher checks before publishing npm, PyPI and crates.io artifacts.
